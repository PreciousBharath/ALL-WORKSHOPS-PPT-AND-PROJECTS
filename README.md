## 🎓 About the Project

A central hub for the **workshop presentations and hands-on projects** I deliver as a technical trainer — covering **Cloud Computing, Blockchain and Prompt Engineering / Generative AI**. Every workshop folder will hold its slide deck, demo code and mini-projects so students can revise and practise after the session.

## ✨ Key Features

- ☁️ **Cloud Computing** — fundamentals, AWS services, storage & deployment demos
- ⛓️ **Blockchain** — cryptography, smart contracts, e-voting & supply-chain projects
- 🪄 **Prompt Engineering** — GenAI basics, prompt patterns and real use-cases
- 📽️ Ready-to-teach **PPT decks** + 🧪 hands-on **mini-projects**

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Cloud | AWS (S3, EC2), Node.js demos |
| Blockchain | Python / JavaScript blockchain demos |
| GenAI | LLM prompting, ChatGPT / Claude |
| Material | PPTX decks · PDFs · source code |
